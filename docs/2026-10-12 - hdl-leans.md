## What the run taught the skills

- **`split_doc.py` numbers a stale line without the part's preamble.** The dry run said
  `purpose.md:10`; the line is at 16, after the part's six-line header. Fixed the same
  evening (the fixture's expected dry run regenerated).
- **The survey's charter detector keys on the word "charter"** (both reps): a router
  whose charter blockquote sits under the `/init` boilerplate, and a journal whose
  first line is charter-like without the word, are flagged S5. Both reps resolved it by
  reading; the detector stays a keyword test, stated as such.
- **The survey does not count a `## State` block as embedded history** (A2 keys on a
  "shipped" or "history" heading); the HlsLibrary rep found the block by reading. A
  dated `##` heading in a router is the stronger signal; the survey could say so.
- **`docs/` cannot be created empty under git** (S5 says create it): deferred to first
  use, the pattern stated in the router. The rule stands; the survey's line could say
  "or state the pattern" when the directory would be empty.
- **The rep's gaps are the owner's calls, not the skill's:** the dated-record pattern
  when a project states none (the owner's global rule won), `docs/Archive/` capitalized,
  a `RELEASING.md` or a skill for release mechanics, one rule file or three.
- **A sibling-keyed guard with no home but a line:** the bitstream trigger from an edit
  under the contract library stays a router line in HlsLibrary, as S8 says; the rep
  placed it exactly there.
