## Tools over prose: 2026-10-12

By the evening of 2026-10-12 the three skills weighed 38.7 KB (9.7k tokens), and the field
loop was finding fewer failures per run than the text it added per failure: capable reps
already did the right thing in most cells, and each RED failure had been paid for with a
clause every later run reads. The measurement that set the direction: italic rationale was
10 percent of each file; the weight was in rule bodies that restated what a script does (T5
2.9 KB, S8 3.4 KB, R30 2.2 KB, M17 1.7 KB) and in shape rules whose precondition a reader
was told to detect (B3 to B6, A2, T1; R12 to R16; M16).

The shape the family moves to: **detection in scripts, judgment in prose, a rule its action
plus one boundary.** A script beside each skill prints what the rules key on, one line per
finding with the rule at the end; the text says what to do; mechanism stays only where a rep
acts on it (S8's homes with their load triggers); rationale lives here; provenance in the
footer's link. SETUP first: `survey.py` (the shapes, the set and its charters, the router's
names, exclusions and chain row, journals and reference docs past budget, embedded history,
the ignore file, the git state) and the text to 10.4 KB from 14.6. AUDIT and MAINTAIN follow
in their own changes (`scope.py`, the in-scope set from the router; `report_check.py`, the
report's required lines).

The gate changes with the shape: a trim claims nothing new, so it earns no RED; it ships
when the representative cells still pass with the trimmed text (one plan-only rep per
fixture family), and a cell that fails names the clause restored, in the shortest form that
passes. The survey's own check is byte-exact output on three baselined fixture copies.
SETUP's regression (five reps, 355k tokens) restored nothing: the trimmed text produced the
morning's plans, and what changed was that every rep planned from the survey's lines and
said what the survey does not detect. The record:
`docs/2026-10-12 - setup-tools-first-regression.md`; the change:
`openspec/changes/archive/2026-10-12-setup-tools-first`.
