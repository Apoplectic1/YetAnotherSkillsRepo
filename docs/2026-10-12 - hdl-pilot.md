## The plans

**HlsLibrary.** The repo has no ARCHITECTURE, DOMAIN, ROADMAP or VERIFICATION; the class
READMEs (Lookaside 38 KB, Streaming 17 KB) and the openspec specs are its reference docs.
The plan is a full SETUP scaffold plus the lean: State (2.9 KB, touched in 35 of 45 commits)
to ROADMAP and a new CHANGELOG; the 12.9 KB element map to a new ARCHITECTURE "merged
against the two specs and the READMEs so the unique remainder lands once"; the 16.7 KB of
gotchas to four path-scoped rule files keyed by class and flow (`hls-core-coding`,
`hls-streaming`, `hls-lookaside`, `hls-flow`) plus `hls-interfaces` for the naming rule;
the router about 6.5 KB afterward. Blocked: the element map already exists in the READMEs
and the specs (a move makes a fourth copy), and the bitstream-rebuild guard fires on files
in the contract library, which no `paths:` here can name.

**ArtyZ7.** T5 on ARCHITECTURE (70.4 KB, seven topics, 86 citations): applied the same day
(`546ba5f` there: seven parts, byte-exact, 2.3 KB index, the router line says so). The
router lean (26.6 → about 8.5 KB): six rule files keyed to the build scripts, the PL
sources, the lane layer, the GEM path, the flash loader, the Theory tooling, with six trigger
lines left. Blocked: the build, XMODEM and bench-NIC guards are command-keyed (a session
that only runs `MakeAll.bat` touches no matching file); the kernel gotchas key to files in
`../../../Library/`; a third of the gotchas already have one to five hits in ARCHITECTURE.
Also noted: VERIFICATION at 39.3 KB would cross the budget by the run's own moves; the
NOTEBOOK index records 39.3 KB for a rolled file that is 22.9 KB on disk.

**AtmlBoards.** The router lean (12.9 → about 7 KB): the three-levels block to a new
ARCHITECTURE, the enumerated `docs/` list to the convention line, three rule files
(`lab-net`, `docs-naming`, `openspec-changes`), the A9 IRQ-wrapper gate to VERIFICATION. T5
on DOMAIN (44 KB: a 22 KB Purpose part, Goals 3 KB, glossary 13 KB, conventions 4.7 KB) and
on ROADMAP (74 KB: one 49.7 KB part of bold paragraphs that T5 cannot cut). Blocked: parts
carry `../..` paths and "this file" that go stale one directory down; the rep believed a
board session never loads the umbrella router. Applied the same day: the "Outside the
system" bullet reconciled with the owner's rule 26 (`3ceffbf` there).
