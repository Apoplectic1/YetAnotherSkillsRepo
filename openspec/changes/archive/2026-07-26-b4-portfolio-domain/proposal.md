# b4-portfolio-domain — proposal

## Why

Portfolio-level standing truth has no sanctioned home under B4's "router only," and the
field hit the consequence twice on 2026-07-26: TSM's maintain surfaced a cross-project
glossary cross-ref loop (two repos each "single-sourcing" toward the other — nobody holds
the content), and the B4 probe at the real Astronomy container reproduced the S7↔B4
collision with divergent resolutions — one rep moved cross-repo contract prose into the
root ROADMAP (wrong charter), the other kept it in the router as a "gotcha"
(router-fattening). Both acknowledged content "no single sub-project owns."
Non-determinism from an unpinned rule. User decision (2026-07-26, probe adjudication):
**Option A** — sanction a thin portfolio DOMAIN.

## What Changes

- **SETUP B4 amended** (in place, R21 precedent): a container root gets the **router, plus
  optionally a thin portfolio `DOMAIN.md`** chartered *cross-repo truth only* (shared
  glossary terms, cross-store disambiguations, cross-repo contracts by pointer where a
  sub-project owns the detail), **plus optionally a thin status/sequencing `ROADMAP.md`** —
  never the rest of the enforced set. Companion rules baked into the amendment:
  - **Owner-project rule:** anything one project's code defines lives in that project's
    docs; the portfolio DOMAIN holds only what no single project owns.
  - **One-way pointers:** sub-projects point up to the portfolio DOMAIN for shared terms;
    the portfolio DOMAIN points down by name for owned detail; never mutual — this is the
    loop breaker.
- **MAINTAIN targeting clause** (small, appended ID): a graduate whose standing truth is
  portfolio-level (spans repos / no in-repo charter home) targets the container's portfolio
  DOMAIN when the convention provides one; absent that, **flag-and-ask** — never improvise
  a cross-repo pointer (interim discipline from NOTEBOOK 2026-07-26 becomes rule text).
- **Gate:** RED evidence exists (probe divergence 1/1-vs-1/1 + the TSM loop); both the
  Astronomy container and TSM are deriving evidence — **poisoned**. GREEN requires a
  synthetic container fixture (a small fictional portfolio: 2–3 sub-projects with routers,
  shared glossary terms, a cross-store disambiguation, an owned contract) — new fixture,
  TidePool-family style.
