# maintain-right-sizing — design

## Context

The graduate side of MAINTAIN has strong machinery (M1, charters, M9/M14 holds); the cut
side is two under-driven classifications (M3/M4) that nothing forces a rep to hunt for.
The description's "periodic journal-health sweep" clause legitimizes scheduled ritual runs
the honesty posture (DOMAIN) explicitly calls process-theater. Field measurements: 12:1
add:remove; back-to-back same-day sweeps with collapsing yield.

## Goals / Non-Goals

**Goals:** the description's trigger surface matches the field-calibrated guidance; every
sweep *searches* for prune/archive candidates and *reports* the run's net effect on the
reference tier.

**Non-Goals:**
- No graduation cap or numeric budget (house precedent: content tests over thresholds; a
  cap would suppress legitimate first-sweep backlogs — early sweeps SHOULD graduate a lot).
- No reference-tier deletion authority for MAINTAIN (removing reference content stays
  AUDIT's job — R28/R10; MAINTAIN's cut side is journal/open-list scoped).
- No scheduling machinery — the trigger list is description text, not runtime logic.

## Decisions

- **D1 — description carries triggers only** (authoring convention): the ~10-changes /
  subsystem-rewrite / journal-visibly-ahead triggers replace "periodic"; shift-left is NOT
  summarized in the description (it's DOMAIN/rule-20 guidance, and descriptions never
  sketch workflow).
- **D2 — M16 is a REQUIRED pass + REQUIRED report slot**, not a prohibition: the failure
  class is omission (cut candidates unsought), so the fix form is a forced search + a slot
  that must be filled ("none found" is a legal answer that must be stated). The net-delta
  line makes ratchet growth visible to the user per run — enforcement stays human.
- **D3 — split gates per half.** The description half REDs via invocation probes (old vs
  new description in a low-yield scenario). The M16 half REDs via planted PR cells; if
  small-fixture reps find them anyway (plausible — legible plants), the no-failure gate
  status-notes that half and only the probe-backed description half plus any
  independently-REDding slot ships. No shipping on field numbers alone.
- **D4 — PR plants live in the standing TidePool fixture** (PR1: a ROADMAP Now/Next item
  whose shipped completion is visible in the journal; PR2: a spent journal record fully
  superseded by a reference doc). Not derived from TSM specifics.

## Risks / Trade-offs

- [Required pass adds tokens to every sweep] → it's one targeted pass over two bounded
  surfaces (open lists + journal headers); trivial next to the fan-out, and it converts
  the 12:1 blind spot into a per-run visible number.
- [Description trigger list goes stale] → the numbers are field-calibrated heuristics
  ("~10"), not contracts; DOMAIN carries the fuller rationale.
- [(b) no-fails] → planned for in D3; honesty over shipping.
