# DOMAIN.md — ReefDash

**Charter:** display + vocabulary conventions for the dashboard.

## Vocabulary
- **Salinity event** — canonical definition lives in DoseKeeper's `DOMAIN.md`
  (`../DoseKeeper/DOMAIN.md`); this app renders the event feed and tags entries with it.
- **Event feed** — the reverse-chronological panel; one row per detected event.

## Display conventions
- Salinity charted in ppt to one decimal; temperature in °C.
